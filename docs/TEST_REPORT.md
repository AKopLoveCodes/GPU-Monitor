`python3 tests/manual/check_live.py` 已通过：

- 逐张核对实时网页 API 与直接 SSH 调用 `nvidia-smi` 返回的 GPU 编号、UUID、型号、显存总量及字节换算。
- 两台各 8 张，合计 16 张；指标包含空闲显存、计算利用率、温度和功耗。
- 第一轮检查读取 gpu-01 的 7 个、gpu-02 的 5 个计算进程，均有用户和命令详情。进程数量随后随实际任务变化。
- 等待下一采集周期后，两个服务器的成功采样时间戳均前进，趋势样本增加。
- 网页、JS、CSS、图标、健康检查端点均返回 HTTP 200。

GPU 利用率和显存随正在运行的任务变化，因此未对不同时刻的可变指标做相等断言；GPU 清单、UUID 和显存容量做了精确核对。

## 故障与恢复

`python3 tests/manual/check_recovery.py` 已通过：

1. 关闭本应用专用 SSH ControlPath 连接，随后自动重建连接并获得新的 GPU 与计算进程样本。
2. 暂停 gpu-01 对应的本地 exporter，使指标请求无法响应；超时后 gpu-01 显示离线，保留的旧 GPU 数据均标记为过期。
3. 故障期间 gpu-02 保持在线，其成功采样时间戳继续前进。
4. 在 `finally` 恢复本地 exporter 后，gpu-01 自动恢复新样本，过期标记清除，计算进程数据恢复。

测试仅对本应用的本地采集进程与专用 SSH 连接进行故障注入，没有暂停、结束或新增远端 GPU 计算任务。完整网络 / VPN 中断未实际切换；其错误与过期数据处理另外由单元测试覆盖。

已验证停止 / 重新启动后台服务，随后两台服务器重新在线。
